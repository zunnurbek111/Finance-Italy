# FinCity 3D — Financial Smart City · Venezia

Интерактивный 3D финансовый умный город в стиле Венеции (факультет Finance).

- 3D-город с каналами, гондолами, мостами и палаццо
- Управление 360°: вращение, зум и сдвиг мышью, кнопка «Облёт 360°»
- Каждое здание можно нажать, после клика открывается информационная панель
- Финансовые инструменты: ключевая ставка, котировки биржи, портфель инвестиций, вклад, кредит, ипотека, городской бюджет, налоги, страхование, P&L рынка

Технологии: HTML, CSS, JavaScript, Three.js.

Запуск: откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Branch: main).
